# KrilyonNEX

**NEX — Natural Expression Expert**

NEX-1 is the first model in the KrilyonNEX project, an experimental AI initiative focused on natural-language understanding and conversational responses, with an initial focus on Azerbaijani.

## Project goals

- Build a modular, maintainable AI project.
- Run experiments using Google Colab.
- Explore open-source language models and fine-tuning.
- Evaluate conversational quality, especially in Azerbaijani.

## Technology

- Python
- PyTorch
- Hugging Face Transformers
- Google Colab
- GitHub

## Status

Early development — NEX-1 is under development and has not yet been evaluated as a production-ready AI model.

## Roadmap

1. Set up the project structure.
2. Select a suitable pretrained language model.
3. Prepare Azerbaijani training and evaluation data.
4. Experiment with fine-tuning.
5. Build and test a conversational interface.
